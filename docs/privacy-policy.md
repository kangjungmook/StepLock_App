# 스텝락 개인정보처리방침

최종 수정일: 2026년 9월 21일

스텝락(StepLock)은 걸음 수 · 수면 시간 · 집중 세션 중 하나를 채우면 지정한 앱의 잠금이
풀리는 습관 관리 앱입니다. 이 문서는 앱이 어떤 정보를 다루고, 어디에 보관하며,
어떻게 지울 수 있는지 설명합니다.

> **연락처:** `여기에 연락받을 이메일을 적어 주세요`
> (Play 스토어 등록 전에 반드시 채워야 합니다.)

## 1. 앱이 다루는 정보

### 1-1. 기기에만 저장되고 외부로 나가지 않는 정보

| 정보 | 용도 | 비고 |
| --- | --- | --- |
| 화면에 떠 있는 앱의 패키지 이름 | 잠글 앱인지 판단 | **저장하지 않고 전송하지 않습니다.** 판단 직후 버립니다 |
| 걸음 수 기준점 | 하루 걸음 계산 | 기기 재부팅 시 다시 계산하기 위한 값 |
| 집중 세션 종료 시각 | 타이머 복구 | |
| 수면 시간 캐시 | 매초 조회를 피하기 위한 임시 보관 | |

앱은 **화면의 내용을 읽지 않습니다.** 무슨 앱이 앞에 있는지만 확인합니다.

### 1-2. 로그인한 경우에만 서버로 전송되는 정보

로그인하지 않고 게스트로 쓰면 **아무 정보도 기기를 떠나지 않습니다.**

| 정보 | 예 |
| --- | --- |
| 계정 식별자와 이메일 | Supabase 인증이 보관 |
| 표시 이름 | 소셜 로그인 시 제공되는 경우 |
| 기기 식별자 | 앱이 만든 임의의 UUID (광고 ID나 기기 고유번호가 아닙니다) |
| 잠금 설정 | 목표 걸음 수, 목표 수면 시간, 목표 세션 수, 조건 on/off, 잠글 앱 목록 |
| 일별 기록 | 날짜별 걸음 수, 수면 분, 완료한 집중 세션 수 (최근 30일) |

목적은 **기기를 바꾸거나 앱을 다시 설치했을 때 설정과 기록을 되찾는 것** 하나입니다.

### 1-3. 건강 관련 정보

걸음 수와 수면 시간은 건강 정보에 해당합니다.

- 걸음 수는 기기의 걸음 센서(`ACTIVITY_RECOGNITION`)에서 읽습니다.
- 수면 시간은 **Health Connect**에서 읽습니다. 수면 조건을 켤 때만 권한을 요청하고,
  거절하면 해당 조건은 켜지지 않습니다.
- 두 값은 잠금 해제 조건 판정과 통계 화면에만 씁니다.
- **광고, 마케팅, 프로파일링에 사용하지 않습니다.**
- Health Connect에서 읽은 데이터를 제3자에게 제공하거나 판매하지 않습니다.

## 2. 하지 않는 것

- **광고를 넣지 않습니다.** 광고 SDK가 없습니다.
- **분석 도구나 크래시 리포터를 넣지 않습니다.** 사용 행태를 추적하지 않습니다.
- **정보를 판매하거나 광고 목적으로 제공하지 않습니다.**
- 법령에 따른 요구가 없는 한 제3자에게 제공하지 않습니다.

## 3. 정보를 보관하는 곳

로그인한 경우 데이터는 **Supabase**(Supabase, Inc.)가 운영하는 데이터베이스에 저장됩니다.
행 수준 보안(Row Level Security)을 적용해 **본인 계정의 행만** 읽고 쓸 수 있습니다.

- Supabase 개인정보처리방침: <https://supabase.com/privacy>

소셜 로그인을 쓰면 해당 사업자(Google, Kakao, Apple)의 인증 절차를 거칩니다.
각 사업자에게 제공되는 정보는 그 사업자의 방침을 따릅니다.

## 4. 보관 기간

- 일별 기록은 **최근 30일분만** 유지하고 오래된 것은 자동으로 사라집니다.
- 계정을 삭제하면 서버의 설정과 기록이 **즉시 함께 삭제**됩니다.
- 앱을 삭제하면 기기에 저장된 정보는 함께 사라집니다.

## 5. 정보를 지우는 방법

### 앱에서 직접

**설정 → 계정 삭제** → 확인하면 다음이 모두 지워집니다.

- 계정
- 서버에 저장된 설정과 일별 기록
- 기기에 남아 있던 기록

되돌릴 수 없습니다.

### 요청으로

앱을 지운 뒤라 앱에서 삭제할 수 없다면 위 연락처로 요청해 주세요.
계정을 확인한 뒤 30일 이내에 삭제하고 처리 결과를 알려드립니다.

자세한 절차는 [계정 및 데이터 삭제 안내](account-deletion.md)를 참고하세요.

## 6. 아동의 개인정보

스텝락은 아동을 대상으로 만든 앱이 아니며, 만 14세 미만 아동의 정보를 의도적으로
수집하지 않습니다.

## 7. 권한을 쓰는 이유

| 권한 | 이유 |
| --- | --- |
| 사용 정보 접근 | 지금 앞에 있는 앱이 잠글 대상인지 확인 |
| 다른 앱 위에 표시 | 잠긴 앱 위에 잠금 화면 띄우기 |
| 신체 활동(`ACTIVITY_RECOGNITION`) | 걸음 수 읽기 |
| 수면 기록 읽기(Health Connect) | 수면 조건 판정 |
| 알림 | 집중 타이머와 감시 상태 표시 |
| 포그라운드 서비스 | 화면이 꺼져도 잠금 감시와 타이머 유지 |
| 부팅 완료 수신 | 재부팅 후 감시 다시 시작 |
| 인터넷 | 로그인과 동기화 (게스트는 사용하지 않음) |

## 8. 변경

이 방침이 바뀌면 이 문서의 최종 수정일을 갱신하고, 중요한 변경은 앱 안에서 알립니다.
