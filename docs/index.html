스텝락 화면 미리보기

걸음 수 · 수면 시간 · 집중 타이머 중 하나를 채워야 쇼츠·릴스의 잠금이 풀리는 습관 관리 앱입니다. 아래 다섯 화면은 StepLock_App 저장소에 구현된 Compose 화면과 같은 OKLCH 토큰·4dp 간격·44dp 터치 영역으로 그렸습니다. 설정의 토글과 스테퍼를 움직이면 홈 게이지와 잠금 화면 문구가 함께 바뀝니다.

LoginTrigger
BottomNavBar

색상

OKLCH로 설계하고 Compose에서는 sRGB로 변환해 씁니다. 배경 oklch(96% 0.012 90), 브랜드 oklch(58% 0.13 165), 잠금 강조 oklch(70% 0.15 55). 순수 블랙 대신 oklch(19% 0.02 260)을 씁니다.

타이포 · 간격

Noto Sans KR 400/500/700/900. 간격은 4dp 그리드, 라운드 14~20dp, 모든 탭 영역은 44dp 이상입니다.

컴포저블

ProgressRing은 홈 44dp와 잠금 200dp에서 같이 쓰고, ConditionRow · GoalStepper · AppListItem · StatusChip으로 화면을 조립했습니다.

범위

화면과 UI 상태까지입니다. 실제 인증, 접근성 서비스 기반 앱 감지, 걸음·수면 데이터 연동은 아직 붙이지 않았습니다.
