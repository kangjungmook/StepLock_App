# 스텝락 계정 및 데이터 삭제 안내

최종 수정일: 2026년 9월 21일

> **연락처:** `여기에 연락받을 이메일을 적어 주세요`
> (Play 스토어 등록 전에 반드시 채워야 합니다.)

이 페이지는 Google Play의 [앱 계정 삭제 요건](https://support.google.com/googleplay/android-developer/answer/13327111)에
따라 제공됩니다. 스텝락 계정과 데이터를 지우는 두 가지 방법을 안내합니다.

## 방법 1 — 앱에서 직접 (권장)

앱이 설치되어 있고 로그인한 상태라면 가장 빠릅니다.

1. 스텝락 실행
2. 하단 탭에서 **설정**
3. 화면 맨 위 **계정** 항목 아래의 **계정 삭제**
4. 내용을 확인하고 **계정과 기록 삭제하기**

누르는 즉시 처리되며 되돌릴 수 없습니다.

## 방법 2 — 이메일로 요청

앱을 이미 삭제했거나 로그인할 수 없다면 위 연락처로 아래 내용을 보내 주세요.

- 제목: `스텝락 계정 삭제 요청`
- 본문: 가입에 사용한 **이메일 주소**

본인 확인 후 **30일 이내**에 삭제하고 결과를 회신합니다.

## 무엇이 지워지나요

| 항목 | 처리 |
| --- | --- |
| 계정(이메일, 계정 식별자) | **즉시 삭제** |
| 서버에 저장된 잠금 설정 | **즉시 삭제** |
| 서버에 저장된 일별 기록(걸음 수 · 수면 · 집중 세션) | **즉시 삭제** |
| 기기에 남아 있던 기록 | 앱에서 삭제한 경우 **함께 삭제** |

계정 데이터는 삭제 후 별도로 보관하지 않으며 백업 사본도 남기지 않습니다.
법령에 따라 보관이 요구되는 정보는 없습니다.

## 계정만 지우고 앱은 계속 쓰고 싶다면

계정을 삭제해도 앱은 **게스트 모드**로 계속 쓸 수 있습니다.
게스트 모드에서는 어떤 정보도 기기를 떠나지 않습니다.
기기에서 앱까지 지우려면 계정 삭제 후 앱을 제거하면 됩니다.
